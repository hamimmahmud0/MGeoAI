# MGeoAI paper evaluation

This directory is generated by `mgeoai paper-evaluate`, except for the human-authored
gold manifest under `gold/`. Never derive or overwrite gold labels from model output.

The default evaluation uses `outputs/deepseek-refusion` for predictions compared with
the manually verified `assets/scraps` subset, `outputs/global-v1` for descriptive and
structural corpus analysis, and bootstrap seed 42 with 2,000 resamples.

```bash
python -m pip install -e '.[dev,evaluation]'
mgeoai paper-evaluate \
  --run outputs/deepseek-refusion \
  --gold evaluation/gold/gold_incidents.json \
  --corpus-run outputs/global-v1 \
  --output evaluation \
  --seed 42
```

Read `results/validation_report.json` before using any number.
`results/paper_metrics.json` is the canonical manuscript source. CSVs retain auditable
denominators and per-record comparisons; PNG and PDF figures derive from the same run.

- Accuracy, precision, recall, F1, and error apply only to supplied human labels.
- Global results describe coverage, completeness, traceability, conflict structure,
  uncertainty, diversity, and efficiency.
- Null is unknown/not available, never zero.
- Map-visible collection-country fallbacks are not resolved incident locations.
- Provenance coverage measures traceability, not factual correctness.
